## 13. Fixing the report (Notepad escaping and duplicates)
Windows 11 Notepad's "Formatted" mode had added backslashes (`\#`, `\-`, `2\.`) to the Markdown files.
```powershell
# find escaped lines
Select-String -Path docs\report.md, docs\research-log.md -Pattern '\\#|\\-|\\\*|&#x20;' | Select-Object -First 10
# remove the backslashes
foreach ($f in "docs\report.md", "docs\research-log.md") {
  $t = Get-Content $f -Raw -Encoding UTF8
  $t = $t -replace '\\([#\-\*_\[\]\(\)\\>|])', '$1' -replace '&#x20;', ' '
  Set-Content $f $t -Encoding UTF8
}
# list headings with line numbers
Select-String -Path docs\report.md -Pattern '^#' | ForEach-Object { "$($_.LineNumber): $($_.Line)" }
# remove escaped dots after numbers ("2\." -> "2.")
$t = Get-Content docs\report.md -Raw -Encoding UTF8
$t = $t -replace '(\d)\\\.', '$1.'
Set-Content docs\report.md $t -Encoding UTF8
# look at, then delete, the duplicate old Method section (lines 33-46)
(Get-Content docs\report.md -Encoding UTF8)[32..45]
$lines = Get-Content docs\report.md -Encoding UTF8
$lines = $lines[0..31] + $lines[46..($lines.Count - 1)]
Set-Content docs\report.md $lines -Encoding UTF8
# look at the landscape brief (was still empty placeholders)
(Get-Content docs\report.md -Encoding UTF8)[0..31]
```
