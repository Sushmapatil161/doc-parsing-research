How to read the times: for each document we take the MEDIAN of the repeats (so one slow repeat cannot distort it), then the mean over documents. Model load = load_s, first run = first_s, warm = warm_s, as measured by scripts/parse_one.py in a fresh process per repeat. A one-time model download is not included: it happened before the benchmark (file dates in .venv/Lib/site-packages/rapidocr/models). Peak memory = highest per-document median.
